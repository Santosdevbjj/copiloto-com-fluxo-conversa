# 🤖 Copiloto com Fluxo de Conversa Personalizado no Microsoft Copilot Studio

Este projeto demonstra como criar um copiloto com fluxo de conversa personalizado utilizando o **Microsoft Copilot Studio**, com foco em:

- Criação de copiloto do zero
- Customização de tópicos
- Personalização de mensagens de erro
- Ajuste da qualidade das respostas com GenAI

---

## 📌 Objetivo

Capacitar desenvolvedores a criar experiências conversacionais otimizadas com o Microsoft Copilot Studio, utilizando recursos de IA generativa e fluxos personalizados.

---

## 🧰 Tecnologias Utilizadas

| Tecnologia                | Descrição                                                                 |
|---------------------------|---------------------------------------------------------------------------|
| Microsoft Copilot Studio | Plataforma low-code para criação de copilotos com IA generativa integrada |
| GenAI                    | Motor de IA para geração de respostas naturais e contextuais              |
| JSON                     | Formato de exportação/importação de tópicos                               |
| Markdown                 | Documentação do projeto                                                    |

---

## 💻 Requisitos

| Tipo       | Requisito                                  |
|------------|---------------------------------------------|
| Conta      | Microsoft 365 com acesso ao Copilot Studio |
| Navegador  | Edge, Chrome, Firefox                      |
| Sistema    | Windows 10+, macOS, Linux                  |
| Internet   | Conexão estável                            |

---

## 🛠️ Como Executar

1. Acesse o [Microsoft Copilot Studio](https://learn.microsoft.com/pt-br/microsoft-copilot-studio/)
2. Crie um novo copiloto em branco
3. Siga os passos descritos em [`docs/resumo-aprendizado.md`](docs/resumo-aprendizado.md)
4. Importe o fluxo `ConsultaSaldo.json` via menu **Tópicos > Importar**
5. Teste o copiloto no simulador e publique
